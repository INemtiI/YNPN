# ЯНПН
**«Я Наглядно Понимаю Неочевидное»** · интерактивная стереометрия для 10 класса с режимом псевдоголограммы (эффект Пеппера).

## Главное
- **Точки где угодно.** Панель «Объекты» как в GeoGebra: каждая точка задаётся координатами `(x; y; z)` или как точка на прямой ребра с параметром t (t < 0 или t > 1 — продолжение ребра). Отношения (AP : PB = 1 : 2, BK = ½·AB, «на грани», «вне тела») показываются сами, из положения точки.
- **Строка ввода:** `K = (1; 0; 2)`, `L = AB 1:2`, `N = AB t=1,5`, `M = середина BC`, `C1`. Повторное имя переопределяет точку. Русские буквы А, В, С тоже понимаются.
- **Инструменты:** Двигать (V), Точка (P), Сечение по трём кликам (C), Угол (A). Точку на ребре можно тянуть за вершину, на продолжение. Свободную точку тянешь по горизонтали, с Shift или кнопкой ↕ по высоте.
- **Метод следов по шагам:** сначала соединяем точки, лежащие в одной грани; затем проекции, точки следа и след ℓ; затем по одной грани за шаг (продлеваем ребро основания до ℓ → Tᵢ → прямая к известной точке). Текущий шаг подсвечен, у каждого шага есть «почему» и список известных точек. Автопоказ: пробел.
- **Тело по точкам:** любой выпуклый многогранник по списку вершин (выпуклая оболочка), готовые примеры, «Из точек списка», «Изменить вершины» у любого тела.
- Сечения тел вращения, углы всех типов, координаты, площади, уравнение плоскости, голограмма 4/3/1 грани, общий экран по коду и QR.

## Запуск
Открыть `index.html`. Для комнат и QR сайт нужно опубликовать по https (GitHub Pages: Settings → Pages → main / root).

## Файлы
`assets/` логотип и иконки · `js/vec.js` математика и разбор чисел · `js/figures.js` тела, оболочка, задачи · `js/section.js` сечения и метод следов · `js/render.js` отрисовка · `js/app.js` интерфейс · `js/holo.js` голограмма · `js/room.js` комнаты · `js/qr.js` QR-коды.
